# MyMobileObsidian

> ⚠️ **个人自用插件 / Personal-use plugin**
>
> 这是我为自己在手机上使用 Obsidian 而写的插件，功能高度贴合个人的笔记结构和使用习惯。
> 仓库设为公开**仅仅是为了通过 [BRAT](https://github.com/TfTHacker/obsidian42-brat) 安装和更新**，并不是面向大众发布的插件。
>
> This is a highly personalized plugin built for my own mobile Obsidian workflow.
> It is public **only so it can be installed and updated via BRAT**. It is not intended for general use.

## 请先阅读 / Read this first

- **不保证适用于你的 Vault**：很多功能依赖我自己的目录结构、标签体系和命名约定，在别的 Vault 中可能无效，甚至产生意料之外的修改。
- **不提供支持**：不接受功能请求，Issue 和 PR 可能不会被处理。
- **随时可能破坏性变更**：没有版本兼容承诺，更新可能改变行为或删除功能。
- **使用风险自负**：如果你仍想尝试，请先**备份 Vault**，并在测试 Vault 中试用。

欢迎参考代码思路，但更建议 fork 后按自己的需求修改。

## 安装（通过 BRAT）

1. 在 Obsidian 中安装并启用 BRAT 插件。
2. BRAT → `Add Beta plugin` → 填入本仓库地址。
3. 在 `设置 → 第三方插件` 中启用本插件。
